## 一、Xbox 手把（有線連手機）

### 連接方式

手把**不接地面站**：手把以 **USB 線**接到**手機**，手機網頁用瀏覽器 **Gamepad API** 讀搖桿/按鍵，經 WebSocket
上行到地面站（詳見 doc/04 §四「控制上行」），地面站再以 ESP-NOW 轉發給 ROV。

- **為何不直連地面站**：手把走 classic BT，連到地面站時會餓死地面站的 Wi-Fi AP（實測：手把連線 →
  AP stations=0、潛水艇 RSSI −127、影像連不上）。故地面站 Bluepad32 **拒絕並斷開手把連線**，僅保留
  BTstack 入口以驅動 `setup()/loop()`。
- **手把供電**：由手機端透過 USB 供電，地面站不負責手把供電（GS 自身供電見 doc/03 §一）。
- 瀏覽器 Gamepad API 不分有線/藍牙：手把改以藍牙配對手機亦等效操控。

### 按鍵對應

| 按鍵 | 功能 | 備註 |
|------|------|------|
| 左搖桿 | 水平推進（前後 + 轉向） | 自動模式下鎖定 |
| 右搖桿 Y 軸 | 深度控制 | 永遠有效（包含自動模式） |
| Y 鍵 | LED 開關（最高優先） | toggle |
| RB 鍵 | 串流模式切換（0 ↔ 1） | 邊緣觸發 |
| LB 鍵 | 即時拍照（存最新串流影格） | 邊緣觸發，模式 0 才有效 |
| Start 鍵 | 緊急停車（latch toggle） | 按一次鎖定（三馬達歸零 + EN 斷開），再按一次解鎖恢復 |

### 地面站搖桿讀取與指令打包

搖桿值不再由本機 USB Host 讀取，而是由**手機 WS 遙控狀態**提供：`gamepad.cpp` 的 `gpAxisLX/LY/RY`、
`gpButton()` 讀取 `gamepadSetRemote()` 存入的值（逾時 500ms 自動歸零 → 失聯中立保護）。

```cpp
// 地面站：每輪從「手機 WS 遙控狀態」取值 → 差速混控 → ESP-NOW 送 ROV
void readXboxAndSend() {
    pollGamepad();                       // 維持 BTstack（無手把連線時等同 no-op）

    int lx = gpAxisLX();                 // 來自手機 WS（gamepadSetRemote）；逾時自動歸零
    int ly = gpAxisLY();
    int ry = gpAxisRY();

    bool btnY = gpButton(GP_Y), btnRB = gpButton(GP_RB),
         btnLB = gpButton(GP_LB), btnStart = gpButton(GP_START);

    // RB 邊緣觸發：串流模式 0/1 切換
    if (btnRB && !s_rbLast) s_streamMode = (s_streamMode == 0) ? 1 : 0;
    s_rbLast = btnRB;

    // LB 邊緣觸發：僅模式 0 送單張拍照
    bool takePhoto = (btnLB && !s_lbLast && s_streamMode == 0);
    s_lbLast = btnLB;

    // Y 邊緣觸發：LED toggle（最高優先）
    if (btnY && !s_yLast) s_ledState = !s_ledState;
    s_yLast = btnY;

    // Start 邊緣觸發：急停 latch（按一次鎖、再按一次解鎖）
    if (btnStart && !s_startLast) s_estop = !s_estop;
    s_startLast = btnStart;

    // 右搖桿 Y → 深度（永遠有效）；左搖桿 → 差速混控
    if (abs(ry) < 2000) ry = 0;
    int depth = map(ry, -32767, 32767, 1023, -1023);
    MotorPair mp = computeDifferential(lx, ly);

    ControlPacket pkt = {};
    pkt.leftMotor  = mp.left;   pkt.rightMotor = mp.right;  pkt.vertMotor = depth;
    pkt.ledOn      = s_ledState; pkt.emergencyStop = s_estop; pkt.autoMode = false;
    pkt.streamMode = s_streamMode; pkt.takePhoto = takePhoto;  pkt.msgType = MSG_CONTROL;
    sendControl(pkt);
}
```

### 螢幕虛擬搖桿（2026-06-07，無手把也能操控）

`app.js` 的 `controlTick`（取代舊 `pollAndSendGamepad`）每 40ms 輪詢，自動偵測手把/虛擬二擇一，
送出完全相同的 WS 訊息（`{t:'c', lx, ly, ry, b}`），GS 端零改動。

- **左搖桿**（`#joy`，146px）：360° Pointer Events，輸出 `lx/ly`（上推 ly<0＝前進）
- **右深度搖桿**（`#depth-joy`/`#depth-thumb`）：垂直單軸，輸出 `ry`（上推＝上升、下拉＝下潛），放開歸零
- **動作鍵**：📷拍照(LB·bit4)、⏺錄影(RB·bit5)、💡燈(Y·bit3)，最短脈衝寬 120ms 防漏按
- 偵測到手把 → 隱藏虛擬控制；無手把 → 顯示虛擬控制
- ⚠ 急停(Start·bit6)未放上虛擬面板

## 一之一、差速轉向演算法（Differential Steering）

### 概念說明

本 ROV 採**差速轉向**（Tank Drive / Differential Steering）：左右馬達速度差形成轉彎，速度和形成前進推力，**不設實體舵面**。

| 搖桿輸入 | 左馬達 | 右馬達 | 結果 |
|----------|--------|--------|------|
| 純前進（↑） | +V | +V | 直線前進 |
| 純右轉（→） | +V | −V | 原地右旋 |
| 斜右前（↗） | +V | 0 | 右弧前進 |
| 斜左前（↖） | 0 | +V | 左弧前進 |

### 設計目標

1. **搖桿推的大小決定速度**：搖桿推越遠 → 速度越快；輕推 = 慢速微調
2. **搖桿推的角度決定轉向程度**：越偏側邊 → 轉彎越急；越偏前後 → 越接近直線

### 演算法：極座標歸一化差速混合

標準 `left = fwd + turn` 做法有一個問題：斜向推滿搖桿時輸出超過 1.0 而被 constrain 截斷，導致「斜角速度比直線速度慢」。改良版使用**歸一化**：讓輸出峰值永遠等於搖桿實際大小（magnitude），覆蓋全方向角度。

```
數學推導：

  x = lx 正規化（右 = +1）
  y = −ly 正規化（前進 = +1，搖桿 Y 軸天生反向）

  r = clamp( sqrt(x²+y²), 0, 1 )    ── 搖桿大小（速度命令）

  rawLeft  = y + x                  ── 教科書式（2026-06-07 改回：與 ROV computeNavigation 一致，left=fwd+turn）
  rawRight = y − x
  peak     = max(|rawLeft|, |rawRight|)

  若 peak > ε：
    leftPow  = rawLeft  × (r / peak)
    rightPow = rawRight × (r / peak)
  否則：
    leftPow = rightPow = 0

  → 輸出之最大絕對值 ≡ r（速度由搖桿大小決定）
  → 輸出之比例 ≡ tan(θ)（轉彎由搖桿角度決定）
```

### 完整實作程式碼

```cpp
#include <cmath>

#define DEADZONE_RATIO 0.06f   // 死區（~2000/32767）

struct MotorPair { int left; int right; };

/**
 * 極座標歸一化差速轉向
 * 輸入：lx, ly ∈ [-32767, +32767]（Xbox 搖桿原始值，ly 向前為負）
 * 輸出：left, right ∈ [-1023, +1023]（BTS7960 PWM 值）
 */
MotorPair computeDifferential(int lx, int ly) {
    // 1. 正規化至 [-1, 1]；Y 軸反向（搖桿前推 ly 為負 → 前進為正）
    float x =  (float)lx / 32767.0f;
    float y = -(float)ly / 32767.0f;

    // 2. 死區
    if (fabsf(x) < DEADZONE_RATIO) x = 0.0f;
    if (fabsf(y) < DEADZONE_RATIO) y = 0.0f;

    // 3. 計算搖桿大小（速度命令），最大值限制為 1.0
    float r = fminf(hypotf(x, y), 1.0f);

    // 4. 差速混合（教科書式（2026-06-07 改回：與 ROV computeNavigation 一致，left=fwd+turn））
    float rawLeft  = y + x;
    float rawRight = y - x;

    // 5. 歸一化：讓輸出峰值等於搖桿大小 r（保持速度比例正確）
    float peak = fmaxf(fabsf(rawLeft), fabsf(rawRight));
    float leftPow, rightPow;
    if (peak > 1e-6f) {
        leftPow  = rawLeft  * (r / peak);
        rightPow = rawRight * (r / peak);
    } else {
        leftPow = rightPow = 0.0f;
    }

    // 6. 轉換至 PWM 整數範圍
    return {
        constrain((int)(leftPow  * 1023.0f), -1023, 1023),
        constrain((int)(rightPow * 1023.0f), -1023, 1023)
    };
}
```

### 行為驗證表（搖桿推滿）

| 搖桿方向 | x | y | rawLeft | rawRight | peak | left | right | 說明 |
|----------|---|---|---------|----------|------|------|-------|------|
| 純前（↑） | 0 | 1 | 1 | 1 | 1 | +1023 | +1023 | 全速前進 |
| 純後（↓） | 0 | −1 | −1 | −1 | 1 | −1023 | −1023 | 全速後退 |
| 純右（→） | 1 | 0 | 1 | -1 | 1 | +1023 | -1023 | 原地旋轉（左右馬達反向） |
| 斜右前 45°（↗）| 0.71 | 0.71 | 1.41 | 0 | 1.41 | +1023 | 0 | 一側出力、弧線前進 |
| 輕推前（50%）| 0 | 0.5 | 0.5 | 0.5 | 0.5 | +511 | +511 | 半速前進 |
| 輕推斜右（50%）| 0.35 | 0.35 | 0 | 0.71 | 0.71 | 0 | +511 | 半速弧線 |

> **關鍵特性**：
> - 斜角推滿（0.71, 0.71）輸出 (0, +1023)，速度等同直線推滿 → 全方向 360° 都能發揮完整速度（歸一化避免截斷）
> - 輕推任意方向，輸出成比例縮小 → 操作手感線性、精確
> - ⚠ 2026-06-07 改回教科書式（左推＝右馬達>左馬達＝左轉），與 ROV 自動導航一致。待實機最終確認。

### 在地面站的整合位置

## 二、控制流向

### 手動操控

```
Xbox 左搖桿 → 差速混控 → ControlPacket → ESP-NOW → ROV
    ↓
BTS7960 RPWM/LPWM → 左右馬達

Xbox 右搖桿 Y 軸 → ControlPacket → ROV → 垂直馬達（永遠有效）
```

### 自動導航

```
手機 Leaflet 地圖點擊航點 → HTTP POST → 地面站
    ↓ ESP-NOW 分塊傳送
ROV 接收航點 → Potential Field + Geofence 逐點導航
    水平馬達：自動控制（左搖桿鎖定）
    垂直馬達：右搖桿永遠有效
```

## 三、馬達 PWM 控制

```cpp
#define PWM_FREQ  20000   // 20kHz，超出可聞範圍
#define PWM_RES   10      // 10-bit，0～1023

void setupMotorPWM() {
    ledcAttach(14, PWM_FREQ, PWM_RES);  // 左馬達 RPWM
    ledcAttach(21, PWM_FREQ, PWM_RES);  // 左馬達 LPWM
    ledcAttach(47, PWM_FREQ, PWM_RES);  // 右馬達 RPWM
    ledcAttach(46, PWM_FREQ, PWM_RES);  // 右馬達 LPWM (避開 UART0 對沖)
    ledcAttach(41, PWM_FREQ, PWM_RES);  // 垂直馬達 RPWM (避開 USB/Strapping 腳位)
    ledcAttach(42, PWM_FREQ, PWM_RES);  // 垂直馬達 LPWM (避開 USB/Strapping 腳位)
}

// speed: -1023（全速反轉）到 +1023（全速正轉）。搖桿推到底＝±1023＝100% duty（無保留）。
void setMotor(uint8_t rpwmPin, uint8_t lpwmPin, int speed) {
    speed = constrain(speed, -PWM_MAX, PWM_MAX);   // PWM_MAX = 1023
    if (speed >= 0) {
        ledcWrite(rpwmPin, speed);
        ledcWrite(lpwmPin, 0);
    } else {
        ledcWrite(rpwmPin, 0);
        ledcWrite(lpwmPin, -speed);
    }
}

// 左馬達裝「反槳」：要與右馬達同向推力，電氣命令需反向（config.h `LEFT_MOTOR_INVERT=1`）。
// 同時涵蓋手動差速與自動導航輸出；改裝正槳則設 0。
void setLeftMotor(int speed) {
#if LEFT_MOTOR_INVERT
    speed = -speed;
#endif
    setMotor(PIN_LEFT_RPWM, PIN_LEFT_LPWM, speed);
}
void setRightMotor(int speed) { setMotor(PIN_RIGHT_RPWM, PIN_RIGHT_LPWM, speed); }
void setVertMotor(int speed)  { setMotor(PIN_VERT_RPWM,  PIN_VERT_LPWM,  speed); }
```

## 四、MCP23017 初始化與安全啟動

```cpp
#include <Wire.h>
#include <Adafruit_MCP23X17.h>

Adafruit_MCP23X17 mcp;

void setupMCP() {
    Wire.begin(1, 2);        // SDA=GPIO1, SCL=GPIO2
    mcp.begin_I2C(0x20);     // A0/A1/A2 全接 GND

    // GPA0～GPA6 全設輸出，預設 LOW
    // EN 全關（馬達不動）、繼電器高電位觸發所以 LOW = 不動作（LED 不亮）
    for (int i = 0; i <= 6; i++) {
        mcp.pinMode(i, OUTPUT);
        mcp.digitalWrite(i, LOW);
    }
}

void enableMotors() {
    // 所有初始化完成後才呼叫，拉高 EN 啟用馬達電路
    for (int i = 0; i <= 5; i++) mcp.digitalWrite(i, HIGH);
}

void emergencyStop() {
    // PWM 全歸零
    ledcWrite(14, 0); ledcWrite(21, 0);
    ledcWrite(47, 0); ledcWrite(46, 0);
    ledcWrite(41, 0); ledcWrite(42, 0);
    // EN 全斷
    for (int i = 0; i <= 5; i++) mcp.digitalWrite(i, LOW);
}
```

## 五、自動導航演算法

### Potential Field + Geofence

- **吸引力**：目標航點對 ROV 產生吸引力，力的方向指向航點
- **排斥力**：Geofence 邊界對 ROV 產生排斥力，防止偏出安全區域
- **合力**：兩者向量相加，轉換為左右馬達差速值

### GPS 精度限制

- Neo-M8N CEP 精度約 **2.5 公尺**
- **最小航點間距：≥ 5 公尺**（否則 GPS 誤差會導致航點判定混亂）
- **航點到達半徑：4 公尺**（距航點 < 4m 視為到達，切換下一個航點）
- 手機 Leaflet UI 設置航點時應提示用戶保持足夠間距

### 航向來源：QMC5883P 羅盤

#### 硬鐵／軟鐵校正

有刷直流馬達的永磁體與運轉電流會產生恆定與變動磁場，若不校正，羅盤讀數可能偏差數十度。

**校正流程**：

1. **硬鐵校正（靜態偏移）**：馬達靜止，將 ROV 水平旋轉 360°，記錄 X/Y 軸最大值與最小值，計算偏移量 `offsetX = (maxX + minX) / 2`，`offsetY = (maxY + minY) / 2`
2. **軟鐵校正（軸向比例）**：計算 X/Y 軸半徑比 `scaleX / scaleY`，修正橢圓為圓形
3. **馬達干擾補償**：分別在馬達靜止與運轉時取樣，建立 PWM 值對應的磁場偏移查表，導航時動態補償

```cpp
float getCorrectedHeading() {
    sensors_event_t event;
    compass.getEvent(&event);

    // 硬鐵校正
    float x = event.magnetic.x - offsetX;
    float y = event.magnetic.y - offsetY;

    // 軟鐵校正
    x *= scaleX;
    y *= scaleY;

    // 馬達干擾補償（簡化版：根據當前 PWM 查表減去偏移）
    x -= motorCompX[currentPWMLevel];
    y -= motorCompY[currentPWMLevel];

    float heading = atan2(y, x) * 180.0 / PI;
    if (heading < 0) heading += 360.0;
    return heading;
}
```

> 實作差異：實機羅盤為 **QMC5883P**，以 `compass.getGaussField(&gx,&gy,&gz)` 取值（非
> Adafruit `getEvent`）；目前先做硬鐵＋軟鐵兩道校正，馬達干擾補償（`motorComp` 查表）仍為 TODO。

#### 手機端自動校準（實作流程）

校準改在**手機網頁**完成，免插序列埠手算。資料路徑：ROV 把**原始（未校正）磁場** `magX/magY`
（Gauss）併入 `TelemetryPacket` → ESP-NOW → 地面站 → WebSocket（`magX/magY`）→ 手機。

操作：航點頁側欄「🧭 校準」開浮層 →「開始收集」→ 把 ROV 放平、水平緩慢轉一整圈
（頁面以 12 個 30° 扇區的「涵蓋度」確認真的轉滿 360°）。網頁即時累計 X/Y 的 min/max，依下式算常數：

```
offsetX = (maxX + minX) / 2          offsetY = (maxY + minY) / 2     # 硬鐵：圓心平移
rX = (maxX - minX) / 2   rY = (maxY - minY) / 2   avg = (rX + rY) / 2
scaleX  = avg / rX                    scaleY  = avg / rY              # 軟鐵：橢圓拉回正圓
```

頁面直接輸出可貼進 `sensors.cpp`（取代 `g_offsetX/Y`、`g_scaleX/Y` 預設值）的 C++ 常數，
重燒 ROV 後航向才準。模型與 ROV `getCorrectedHeading()` 的 `x=(gx-offX)*scaleX` 完全一致；
此校正只決定 `scaleX/scaleY` 的**比例**（atan2 對共同縮放不變），故能精準還原航向。

> ✅ **2026-05-31 實機校正值**（板攤平、水平轉滿一圈）：`g_offsetX/Y=-0.237/-0.135`、
> `g_scaleX/Y=1.0484/0.9559`，已寫入 `sensors.cpp`。

> 校準在馬達**裝妥的最終機身**上、現場進行最準；磁偏角（台北約西偏 4.5°）目前未補，
> 自動導航的目標方位（真北）與羅盤（磁北）會有固定夾角，待補。

#### 羅盤擺設指引（旋轉／傾斜／位置）

擺設的三個自由度影響「性質」不同，分開處理：

| 因素 | 造成 | 「轉一圈」校準能吃掉？ | 處理 |
|------|------|----------------------|------|
| **水平旋轉角**（繞垂直軸，沒對準艇首） | **固定偏移**（各方向差同一角度） | ❌（校準只置中/拉正，不旋轉基準） | 物理上免對準艇首；用一個 `HEADING_OFFSET_DEG` 常數補掉（與磁偏角合併） |
| **傾斜**（俯仰／側傾，沒裝平） | **隨方向變化**的誤差 | ❌（需 IMU 傾斜補償，本專案無） | **務必裝平**（對齊艇正常浮姿）；只用 X/Y 兩軸算航向，前提是水平 |
| **位置**（離馬達／電流線遠近） | 靜態磁鐵→固定偏移；**馬達電流→動態偏移**（隨油門變） | 靜態✅／**動態❌** | 離馬達/ESC/電流線越遠越好；**在最終位置校準**（吃掉靜態） |

#### 馬達動態干擾能補嗎？能，但要另做 `motorComp`（非「轉一圈」校準）

「轉一圈」是**馬達關著**的靜態校準，抓不到動態。要補馬達電流干擾需另一道補償：

- **原理**：電流產生的磁場 `B ∝ I`（Biot-Savart）；油門/PWM 已知 → 可建「每單位 PWM → 磁場偏移」係數，
  runtime 先從 `magX/magY` 扣掉，再走 offset/scale + `atan2`。
- **量測程序**：艇**固定不動**→馬達關記基準；左右水平馬達各自 0→滿（**正、反兩向**）記每檔 `magX/Y` 變化 → 得 `kX/kY` 小表（內插）。
- **注意**：電流反向→係數變號；PWM↔電流非線性→小表優於單一線性；INA260 只量**總**電流（不分顆）→ 用**各馬達 PWM** 當索引較乾淨。
- **務實順序**：① 先測（艇固定，比較「馬達關」vs「滿油門」航向漂多少）→ 漂很小就不必補；
  ② 漂大優先**拉開距離**（場強隨距離快速衰減）；③ 拉不開再做 `motorComp`。

> 待辦：`HEADING_OFFSET_DEG`（裝設旋轉＋磁偏角，單一常數）與 `motorComp`（馬達動態補償）皆尚未實作；
> 後者建議先用上述「先測」確認確有需要再做。

## 六、PID 深度控制

使用 QuickPID 函式庫，控制垂直馬達維持目標深度。

```cpp
#include <QuickPID.h>

float depthInput, depthOutput, depthSetpoint;
QuickPID depthPID(&depthInput, &depthOutput, &depthSetpoint);

void setupDepthPID() {
    depthPID.SetTunings(2.0, 0.5, 0.1);        // Kp, Ki, Kd（需實測調整）
    depthPID.SetOutputLimits(-1023, 1023);       // 對應馬達 PWM 範圍
    depthPID.SetSampleTimeUs(100000);            // 100ms = 10Hz
    depthPID.SetMode(depthPID.Control::automatic);
}

void updateDepthControl() {
    depthInput = ms5837.depth();                 // 當前深度（公尺）
    depthPID.Compute();
    setMotor(41, 42, (int)depthOutput);          // 垂直馬達（RPWM=41, LPWM=42，見 §三；44/46 為舊筆誤，44 是 GPS 腳）
}
```

右搖桿永遠有效：右搖桿輸入值直接覆蓋 PID 輸出，放開搖桿後恢復 PID 控制。

## 八、緊急停車（Start 鍵，latch toggle）

```
Start 邊緣觸發 → 切換急停鎖定（按一次鎖、再按一次解鎖）→ 持續送出當前 latch 值
    ↓ ESP-NOW → ROV
鎖定中：三馬達 PWM 歸零 + MCP23017 GPA0～5 拉 LOW（斷開 EN）→ 微正浮力自動上浮
解鎖後：ROV 偵測「急停→正常」轉換 → 重新 enableMotors() 致能 EN → 恢復操控
```

> ROV 端 `applyControl` 把急停列為最高優先：`pkt.emergencyStop` 為真就 `emergencyStop()` 並 return；
> 偵測到由急停轉回正常時呼叫 `enableMotors()` 重新致能（EN 一旦拉低不重新致能就回不來）。

## 十一、ROV setup() 初始化順序

```cpp
void setup() {
    Serial.begin(115200);         // USB CDC，不需指定腳位
    Wire.begin(1, 2);             // I²C
    setupMCP();                   // MCP23017 初始化（EN 預設關閉，繼電器不動作）
    setupMotorPWM();              // PWM 初始化（輸出為 0）
    setupCamera();                // OV5640 攝影機
    SD_MMC.begin("/sdcard", true);// SD 卡（1-bit 模式）
    setupWifi_ROV();              // Wi-Fi STA 連入地面站 AP
    setupESPNOW_ROV();            // ESP-NOW 初始化
    setupDepthPID();              // PID 深度控制
    // ... 感測器初始化（GPS、羅盤、水壓、電流計）...
    enableMotors();               // 最後才啟用馬達 EN
}
```
