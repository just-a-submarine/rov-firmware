## 一、整體架構總覽

### 網路拓樸

```
Xbox 手把 ──藍牙──→ 手機瀏覽器（Gamepad API 當控制器）
                       ├─ WebSocket ──────→ 地面站 ESP32（192.168.4.1）  控制上行 + 遙測下行（5–10Hz）
                       ├─ HTTP POST ──────→ 地面站 ESP32                  航點上傳
                       └─ MJPEG <img> ────→ ROV ESP32（192.168.4.100）   影像直連（不經地面站）

地面站 ESP32（純 AP，192.168.4.1）
  └─ ESP-NOW ↕ ROV ESP32（STA，192.168.4.100）   控制/航點 ↓　遙測 ↑
```

> **控制來源已改**：手把不再接地面站。手把藍牙配對到**手機**，手機網頁用 Gamepad API 讀搖桿/按鍵，
> 經 WebSocket 上行到地面站；地面站再以 ESP-NOW 轉發給 ROV。地面站 Bluepad32 僅保留 BTstack 入口、
> **拒絕手把藍牙連線**（手把直連地面站的 classic BT 會餓死 Wi-Fi AP，實測 AP stations=0）。

### 各裝置職責

| 裝置 | 負責 | 不負責 |
|------|------|--------|
| 地面站 ESP32 | SoftAP、WebSocket（收手機控制上行 + 推遙測）、HTTP 接收航點、ESP-NOW 轉發 | 影像（完全不碰）、手把藍牙（拒接） |
| ROV ESP32 | 馬達控制、感測器讀取、ESP-NOW 收發、MJPEG HTTP Server（esp_http_server） | — |
| 手機瀏覽器 | 地圖、遙測顯示、航點設置、影像顯示、**讀手把(Gamepad API)當控制器並經 WS 上行** | — |
| Xbox 手把 | 藍牙連「手機」，由手機網頁 Gamepad API 讀取搖桿與按鍵值 | 不直連地面站 |

## 二、Wi-Fi 配置

### 模式選擇

- **地面站**：純 AP 模式（`WIFI_MODE_AP`），不使用 APSTA，避免 STA home channel 強制覆蓋 AP channel 的陷阱
- **ROV**：純 STA 模式（`WIFI_MODE_STA`），連入地面站 AP
- ESP-NOW 在 AP/STA 模式下均可正常運作，頻道自動跟隨 Wi-Fi

### 地面站初始化

```cpp
#define WIFI_CHANNEL 1
#define AP_SSID      "ROV_GS"
#define AP_PASS      "rov12345"

void setupWifi_GS() {
    WiFi.mode(WIFI_MODE_AP);
    WiFi.softAP(AP_SSID, AP_PASS, WIFI_CHANNEL);
    esp_wifi_set_ps(WIFI_PS_NONE);  // 關閉省電，防漏包

    Serial.print("GS AP MAC: ");
    Serial.println(WiFi.softAPmacAddress());  // 記下這個，填入 ROV peer_addr
}
```

### ROV 初始化

```cpp
void setupWifi_ROV() {
    WiFi.mode(WIFI_STA);
    WiFi.config(IPAddress(192,168,4,100),   // 固定 IP，手機 <img src> 不會失效
                IPAddress(192,168,4,1),     // Gateway = 地面站
                IPAddress(255,255,255,0));
    WiFi.begin(AP_SSID, AP_PASS);
    esp_wifi_set_ps(WIFI_PS_NONE);

    Serial.print("ROV STA MAC: ");
    Serial.println(WiFi.macAddress());  // 記下這個，填入地面站 peer_addr
}
```

## 三、ESP-NOW 配置

### MAC 對應規則（最容易踩坑）

ESP32 的 AP 介面與 STA 介面有不同 MAC（AP MAC = Base MAC 最後 byte + 1）。

| 端 | `ifidx` | `peer_addr` 填入 |
|----|---------|-----------------|
| 地面站新增 ROV 為 Peer | `WIFI_IF_AP` | ROV 的 **STA MAC** |
| ROV 新增地面站為 Peer | `WIFI_IF_STA` | 地面站的 **AP MAC** |

`peer.channel = 0` 表示跟隨本機當前頻道，最安全，不需硬填頻道號。

若頻道不匹配，ESP-NOW 會**靜默失敗**（send callback 回報 `ESP_NOW_SEND_FAIL`，無明確錯誤訊息）。

### 地面站 ESP-NOW 初始化

```cpp
uint8_t rov_sta_mac[] = {0xXX, 0xXX, 0xXX, 0xXX, 0xXX, 0xXX};  // ROV 的 STA MAC

void setupESPNOW_GS() {
    esp_now_init();
    esp_now_register_recv_cb(onDataRecv_GS);
    esp_now_register_send_cb(onDataSent_GS);

    esp_now_peer_info_t peer = {};
    memcpy(peer.peer_addr, rov_sta_mac, 6);
    peer.channel = 0;
    peer.ifidx   = WIFI_IF_AP;   // 地面站用 AP 介面
    peer.encrypt = false;
    esp_now_add_peer(&peer);
}
```

### ROV ESP-NOW 初始化

```cpp
uint8_t gs_ap_mac[] = {0xXX, 0xXX, 0xXX, 0xXX, 0xXX, 0xXX};  // 地面站的 AP MAC

void setupESPNOW_ROV() {
    esp_now_init();
    esp_now_register_recv_cb(onDataRecv_ROV);
    esp_now_register_send_cb(onDataSent_ROV);

    esp_now_peer_info_t peer = {};
    memcpy(peer.peer_addr, gs_ap_mac, 6);
    peer.channel = 0;
    peer.ifidx   = WIFI_IF_STA;  // ROV 用 STA 介面
    peer.encrypt = false;
    esp_now_add_peer(&peer);
}
```

### ESP-NOW 資料結構

```cpp
// 地面站 → ROV（控制指令）
struct ControlPacket {
    int16_t  leftMotor;     // -1023 ～ +1023
    int16_t  rightMotor;
    int16_t  vertMotor;
    bool     ledOn;
    bool     emergencyStop;
    bool     autoMode;
    uint8_t  streamMode;    // 0 = 純串流，1 = 串流 + SD 錄影
    bool     takePhoto;     // true = 觸發單張拍照（LB 邊緣觸發，純串流模式下有效）
    uint8_t  msgType;       // 0=控制, 1=航點塊, 2=ACK
} __attribute__((packed));

// ROV → 地面站（遙測）
struct TelemetryPacket {
    float    lat;
    float    lng;
    float    depthM;
    float    currentA;
    float    powerW;
    uint8_t  batPct;
    int8_t   rssi;
    uint8_t  streamMode;       // ROV 確認回傳
    uint8_t  navWaypointIdx;   // 自動導航目標航點索引（0xFF = 未導航）
    float    navDistanceM;     // 距目標航點距離（公尺）
    bool     photoAck;         // 拍照完成確認
    bool     ledOn;            // 目前燈實際狀態（Y 鍵開或深度>5cm 自動開）
    uint8_t  msgType;          // 3=遙測
} __attribute__((packed));
```

## 四、WebSocket 遙測

### 地面站 WebSocket Server

```cpp
#include <ESPAsyncWebServer.h>  // ESP32Async fork
#include <ArduinoJson.h>

AsyncWebServer server(80);
AsyncWebSocket ws("/ws");

void broadcastTelemetry(TelemetryPacket& pkt) {
    JsonDocument doc;
    doc["lat"]       = pkt.lat;
    doc["lng"]       = pkt.lng;
    doc["depth"]     = pkt.depthM;
    doc["current"]   = pkt.currentA;
    doc["power"]     = pkt.powerW;
    doc["bat"]       = pkt.batPct;
    doc["rssi"]      = pkt.rssi;
    doc["streamMode"]= pkt.streamMode;
    doc["navWpIdx"]  = pkt.navWaypointIdx;
    doc["navDistM"]  = pkt.navDistanceM;
    doc["photoAck"]  = pkt.photoAck;
    doc["led"]       = pkt.ledOn;       // 燈實際狀態（手機顯示琥珀/灰）

    size_t len = measureJson(doc);
    auto *buf = ws.makeBuffer(len);
    if (buf) {
        serializeJson(doc, buf->get(), len + 1);
        ws.textAll(buf);
    }
}
```

推送頻率：**5–10Hz（200–100ms 間隔）**，超過 20Hz 會擠壓 ESP-NOW 無線電時間。

### 控制上行（手機 → 地面站，同一條 WS）

控制不再來自手把直連。手機網頁用 **Gamepad API** 輪詢（~25Hz）讀手把搖桿/按鍵，打包成 JSON 經
**同一條 WebSocket** 上行到地面站；地面站 `WS_EVT_DATA` 收到後存入遙控狀態（`gamepadSetRemote`），
`readXboxAndSend()` 每輪從中取值做差速混控後以 ESP-NOW 送 ROV。逾時（`GP_WS_TIMEOUT_MS` 500ms）未收到
即視為失聯 → 搖桿軸歸零、按鍵清除（中立保護）。

```javascript
// 手機端：Gamepad API 輪詢 → WS 上行（lx/ly/ry：-32767~32767；buttons：bitmask）
function pollGamepadAndSend() {
    const gp = navigator.getGamepads()[0];
    if (!gp || ws.readyState !== WebSocket.OPEN) return;
    const ax = v => Math.round(v * 32767);
    let btns = 0;
    gp.buttons.forEach((b, i) => { if (b.pressed) btns |= (1 << i); });
    ws.send(JSON.stringify({
        t: 'ctl',
        lx: ax(gp.axes[0]), ly: ax(gp.axes[1]), ry: ax(gp.axes[3]),
        btns
    }));
}
```

```cpp
// 地面站端：WS_EVT_DATA 收控制 JSON → gamepadSetRemote（gamepad.cpp 讀此值）
void onWSData(uint8_t* data, size_t len) {
    JsonDocument doc;
    if (deserializeJson(doc, data, len)) return;
    if (doc["t"] == "ctl")
        gamepadSetRemote(doc["lx"], doc["ly"], doc["ry"], doc["btns"]);
}
```

> 按鍵 bitmask 位元順序須與地面站 `GpButton` 列舉一致（A,B,X,Y,LB,RB,Start,Back）。

### 手機瀏覽器 WebSocket 自動重連

```javascript
let ws, reconnectDelay = 1000;
let photoToastTimer = null;

function connectWS() {
    ws = new WebSocket('ws://192.168.4.1/ws');
    ws.onmessage = (e) => {
        const d = JSON.parse(e.data);
        updateTelemetry(d);
        updateStreamModeBadge(d.streamMode);
        updateRSSIWarning(d.rssi);
        updateNavStatus(d.navWpIdx, d.navDistM);
        if (d.photoAck) showPhotoToast();
        reconnectDelay = 1000;
    };
    ws.onclose = () => {
        setTimeout(connectWS, reconnectDelay);
        reconnectDelay = Math.min(reconnectDelay * 2, 30000);
    };
}
connectWS();
```

## 五、航點上傳

### 採用 HTTP POST（非 WebSocket）

航點上傳是一次性操作，HTTP POST 有明確狀態碼回應（200/400/500），比 WebSocket fire-and-forget 更可靠。

### 地面站端接收

```cpp
server.on("/api/waypoints", HTTP_POST,
    [](AsyncWebServerRequest *req) {},
    nullptr,
    [](AsyncWebServerRequest *req, uint8_t *data, size_t len, size_t index, size_t total) {
        JsonDocument doc;
        deserializeJson(doc, data, len);
        JsonArray wps = doc["waypoints"];

        waypointCount = 0;
        for (JsonObject wp : wps) {
            waypoints[waypointCount].lat   = wp["lat"];
            waypoints[waypointCount].lng   = wp["lng"];
            waypoints[waypointCount].order = wp["order"];
            waypointCount++;
        }
        sendWaypointsToROV();
        req->send(200, "application/json", "{\"status\":\"ok\"}");
    }
);
```

### ESP-NOW 分塊傳輸

ESP-NOW 封包上限 250 bytes，每塊可裝 **14 個航點**（14 × 17 bytes = 238 bytes + 5 bytes 標頭）。50 個航點只需 4 個封包。

```cpp
struct WaypointChunk {
    uint8_t  msgType;       // 1 = 航點塊
    uint8_t  seqNum;
    uint8_t  totalChunks;
    uint8_t  chunkIndex;
    uint8_t  wpCount;
    struct { double lat; double lng; uint8_t order; } wps[14];
} __attribute__((packed));

void sendWaypointsToROV() {
    int totalChunks = (waypointCount + 13) / 14;
    for (int c = 0; c < totalChunks; c++) {
        WaypointChunk chunk;
        chunk.msgType     = 1;
        chunk.totalChunks = totalChunks;
        chunk.chunkIndex  = c;
        chunk.wpCount     = min(14, waypointCount - c * 14);
        for (int i = 0; i < chunk.wpCount; i++) {
            int idx = c * 14 + i;
            chunk.wps[i].lat   = waypoints[idx].lat;
            chunk.wps[i].lng   = waypoints[idx].lng;
            chunk.wps[i].order = waypoints[idx].order;
        }
        esp_now_send(rov_sta_mac, (uint8_t*)&chunk, sizeof(chunk));
        delay(50);
    }
}
```

## 六、地圖與離線策略

### Leaflet.js + 離線預打包圖磚

現場為**純 AP、無對外網路**：手機連上地面站 ESP32 AP 後，Android 多數裝置會停用行動數據，
線上圖磚（OSM/Google）一律載不到。因此**不走線上圖磚**，改將「四個目標水域」的底圖
**預打包進 LittleFS** `data/www/tiles/{z}/{x}/{y}.png`，Leaflet 指向本地路徑離線顯示。
（同理不使用 Google Maps：其 JS API 需從 Google CDN 載入，AP 環境下無法可靠載入。）

- **四場域**：外雙溪下游（雙溪濕地公園→福林橋）、大湖公園、碧湖公園、基隆河美堤/迎風河濱。
- **圖源**：CARTO Voyager（底圖＝OSM 資料、免金鑰 raster，允許小量離線快取）；
  **OSM 官方 `tile.openstreetmap.org` 禁止批次下載**（會回 200＋「Access blocked」圖，勿用）。
  備援可切 Esri 衛星（`fetch_tiles.py` 的 `SOURCE`）。
- **產生工具** `tools/fetch_tiles.py`：bbox→tile 換算、循序下載、雷同度防呆（偵測封鎖頁）、
  Pillow 量化壓縮、`--optimize-only`。z15–17、166 張、壓縮後 ~2.1MB（跨場域去重，相鄰磚共用）。

```javascript
const tiles = L.tileLayer('/tiles/{z}/{x}/{y}.png',
    { minZoom: 15, maxZoom: 19, maxNativeZoom: 17, errorTileUrl: 透明圖 });
```

### 操作感：硬邊界 + 能滑＝看得到的圖磚

- `maxBoundsViscosity: 1`（滑到邊界硬停、不回彈）、`zoomControl: false`（手機雙指縮放，移除 +/- 鈕）。
- `maxBounds` **動態＝實際圖磚覆蓋**：把場域 bbox 外擴到 256px 磚界（≥bbox），並於 `zoomend` 依當下
  原生 zoom 重算 → **每個縮放層級「能滑的範圍」正好等於「螢幕看得到的圖磚」**，不露黑邊。

### 即時艇位 marker（顯示「潛水艇」位置，非操作者）

- marker 取自 **`TelemetryPacket.lat/lng`**（ROV 板載 GPS，經 ESP-NOW→GS→WS 下推），**不是**手機 Geolocation。
  ROV 一有有效 GPS fix（`lat/lng` 非 0,0、天空可見）即**自動畫上**並逐筆更新位置。
- **航向箭頭**：`TelemetryPacket` 目前**無 heading 欄**，故用 GPS 連續兩點位移推算 course-over-ground
  （位移 **≥3m** 才更新方向）；尚未位移（剛開機/靜止）顯示**脈動圓點**，一移動轉成指向艇首的**箭頭**。
  前端已預留 `d.heading` 接口，遙測一帶真羅盤航向即自動改用。
- ⚠ 地圖**不自動切場域**：ROV 在哪個水域就要先點對應 chip，且該場域圖磚要涵蓋其座標才看得到。

### LittleFS 檔案架構

```

├── index.html
├── style.css / app.js
```

## 七、地面站 setup() 初始化順序

```cpp
void setup() {
    Serial.begin(115200);
    setupWifi_GS();       // SoftAP 啟動（必須在 ESP-NOW 之前）
    setupESPNOW_GS();     // ESP-NOW 初始化
    LittleFS.begin();
    server.serveStatic("/", LittleFS, "/www/")
          .setDefaultFile("index.html")
          .setCacheControl("no-cache");   // 改版後手機不吃舊快取
    ws.onEvent(onWSEvent);                // WS_EVT_DATA：收手機控制 → gamepadSetRemote
    server.addHandler(&ws);
    server.begin();
    setupGamepad();       // Bluepad32：保留 BTstack 入口；拒接手把藍牙（控制走手機 WS）
}

void loop() {
    ws.cleanupClients();
    readXboxAndSend();    // 從手機 WS 遙控狀態取值 → 差速混控 → ESP-NOW 送 ROV（~100Hz）
}
```

## 八、常見踩坑清單

| 問題 | 原因 | 解法 |
|------|------|------|
| ESP-NOW 靜默失敗 | ifidx 或 peer MAC 填錯 | GS 填 ROV 的 STA MAC + `WIFI_IF_AP`；ROV 填 GS 的 AP MAC + `WIFI_IF_STA` |
| 頻道不匹配導致失敗 | APSTA 模式 STA 頻道覆蓋 AP 頻道 | GS 改用純 AP 模式（已修正） |
| 手機看不到影像 | ROV IP 被 DHCP 動態分配 | ROV 設定固定 IP 192.168.4.100 |
| ESP-NOW 漏包 | Wi-Fi 省電模式 | 兩端均設 `esp_wifi_set_ps(WIFI_PS_NONE)` |
| 手把藍牙連地面站餓死 Wi-Fi AP | classic BT 連線佔無線電 → AP stations=0、ROV −127、影像連不上 | 手把改配對到「手機」；地面站 Bluepad32 拒絕並斷開手把連線、僅留 BTstack 入口 |
| WebSocket 斷線後無法恢復 | 未實作自動重連 | 瀏覽器端實作指數退避重連 |
| 線上圖磚/Google Maps 載不到 | 手機連 ESP32 AP 後 Android 停用行動數據 | 改用 Leaflet.js + LittleFS 離線預打包圖磚（`/tiles`） |
| 圖磚抓回全是同一張 | OSM 官方禁批次下載、回「Access blocked」圖 | 改用 CARTO Voyager；`fetch_tiles.py` 內建雷同度防呆 |
